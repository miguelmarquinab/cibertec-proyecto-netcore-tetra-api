8. Endpoints que tendrás en Swagger

Cuando ejecutes, tendrás estos endpoints:

Listar radios
GET /api/radios
Buscar radios
GET /api/radios?texto=Motorola
Obtener por id
GET /api/radios/1
Listar modelos
GET /api/radios/modelos
Listar estados
GET /api/radios/estados
Registrar radio
POST /api/radios

Body:

{
  "mod_id": 1,
  "esr_id": 1,
  "serie": "SERIE-0001",
  "fecha_ingreso": "2026-04-19T00:00:00",
  "rad_activo": true
}
Actualizar radio
PUT /api/radios/1

Body:

{
  "mod_id": 2,
  "esr_id": 2,
  "serie": "SERIE-0001-ACT",
  "fecha_ingreso": "2026-04-19T00:00:00",
  "rad_activo": true
}
Eliminar radio
DELETE /api/radios/1

EXEC dbo.usp_asignacionRadio_eliminar_logico
    @p_asr_id = 1;


    9) Observación importante

Tu tabla asignacionRadios define asr_id como INT PRIMARY KEY, pero no es identity en el script. Por eso, en el SP de guardado usé:

SELECT @nuevoId = ISNULL(MAX(asr_id), 0) + 1
FROM dbo.asignacionRadios;
